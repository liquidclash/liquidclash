# Tono Windows 0.0.1 — 卡死机器的恢复说明与本次修复

**日期:** 2026-08-02
**版本:** 0.0.1（Windows 测试线重新起版本号；`0.0.2` 保留给"脱离试验状态、真正可用"的那一版）
**取代:** Test 6 / Test 5 / Test 2–4（全部停用）

---

## 0. 给客户的操作（最重要）

那台机器目前是**既卸不掉也装不上**的死锁状态。按这个顺序做：

1. **重启电脑。** 清掉卡死的服务进程。
2. 开机后**不要打开 Tono**，直接运行 `Tono_0.0.1_x64-setup.exe`。
3. 安装器会出现"已安装其他版本"的选择页。**必须选第二项「不卸载，直接安装」**（Don't uninstall）。
   - 为什么：0.0.1 相对已装的 2.5.4 是降级，该页**默认勾选的是「先卸载再安装」**，那会去运行机器上那个**旧的、坏掉的卸载器**。新包里的修复此时还没上机，救不了它。
   - 选第二项后新文件直接覆盖，安装器自带的新服务安装程序会强制替换卡死的服务。
4. 装完打开 Tono，**左下角应能看到 `v0.0.1`**——以此确认装对了版本（截图/拍照即可核对）。
5. 左侧应出现 **仪表盘 / 节点 / 账户 / 设置** 四项。进「节点」页**先选一个服务器**，再回仪表盘点连接。
   - 如果没选节点就点连接，现在会**自动跳到节点页**（不再是点了没反应）。
6. 装上 0.0.1 之后，机器上的安装/卸载器就是修好的版本，以后卸载和升级都不会再卡死。

如果第 2 步的安装仍然失败，把安装器的错误文字拍下来，并取 `%APPDATA%\com.raydocs.tono\logs\latest.log`。

## 1. 本次实际修了什么（对应客户的三个症状）

### 症状一：界面塌陷（侧栏变成几个空白方块、卡片贴左）

**诊断：** 整套布局样式在那台机器上没有生效。证据吻合每一个细节——logo 顶到角落（丢了 padding）、导航按钮退化成 Windows 原生按钮（丢了 `border:none`/`background:transparent`）、连接卡片贴左（丢了 flex 居中），而卡片本身正常（它用的是内联样式，不受影响）。原因是布局样式过去靠 React 运行时注入一个 `<style>` 标签，注入环节在该 WebView2 环境里出问题就整体塌掉。

**修复（两层）：**
1. 布局样式从「运行时注入」改为「**构建期 CSS 文件 + `<link>` 加载**」（`tono-ui/tono.css`）。
2. 更狠的一层：外壳、侧栏、导航按钮、登录页、仪表盘及其中心栈的**结构性属性同时内联到组件上**（共享 `TONO_PAGE_LAYOUT`）。**即使 CSS 一个字节都没加载，界面也不会塌。**

### 症状二：点连接没反应

**诊断：** 因为侧栏坏了进不了节点页，从没选过节点；后端在前置校验就拒绝连接，而错误提示渲染在**窗口顶部**——离按钮很远，拍屏时甚至在画面外。

**修复：** 没选节点/节点失效时**自动跳转到节点选择页**；其他错误改到**连接按钮正下方**显示。

### 症状三：卸载中止，卸不掉

**诊断（比预想更严重）：** 共享的 `stop_windows_service` 优雅停止超时（20 秒）就直接失败，而**卸载器和安装器都调用它**——所以是"卸不掉也装不上"的死锁。此外卸载器在拿不到 owner 锁（孤儿守护进程占着）时也会直接放弃。NSIS 一收到非零退出码就整体 Abort，没有任何出路。

**修复：**
- `stop_windows_service` 增加**强制终止**：先抑制 SCM 崩溃自启动作，从 `QueryServiceStatusEx` 取 pid（pid 文件兜底），`TerminateProcess`，再等 SCM 报告 Stopped。**安装和卸载同时受益**（下沉到共享层）。
- 卸载器在 owner 锁被孤儿守护进程占用时同样升级为强制终止；并在"服务不存在且无任何拦截状态"时**直接判定为已干净、退出 0**。
- 卸载结果改为**分级退出码**：`0` 干净 / `2` **已证明解除拦截**但某个收尾步骤失败（NSIS 记录日志后**继续卸载**，这正是原来的死胡同）/ `3` **无法证明网络已恢复**（NSIS 仍然中止并保留恢复文件，但给出可执行的提示）。任何无法解析的结果都按阻断处理。

**fail-closed 不变式保持：** 强制终止严格发生在解除拦截**之前**，且不移除任何 WFP/DNS/意图状态；解除拦截之前（含解除本身）的任何失败都映射为 `3`；只有解除成功后才会删除服务和文件。

### 附带
- 侧栏底部**常驻显示版本号**——客户全靠拍照沟通，以前无从判断装的是哪个包。
